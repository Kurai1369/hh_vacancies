## 📖 О проекте

**hh_vacancies** — это консольное приложение, которое:
1. Получает данные о работодателях и их вакансиях через публичный API hh.ru
2. Сохраняет информацию в реляционную базу данных PostgreSQL
3. Предоставляет интерактивный интерфейс для анализа собранных данных

Проект разработан с соблюдением принципов чистого кода, типизации и модульной архитектуры.

---

## ✨ Функционал

### Сбор данных
- 🔹 Поиск работодателей по заранее заданному списку (минимум 10 компаний)
- 🔹 Получение информации о компании: название, описание, сайт, логотип
- 🔹 Сбор вакансий работодателя: название, зарплата, опыт, тип занятости, ссылка

### Хранение данных
- 🔹 Автоматическое создание базы данных и таблиц при первом запуске
- 🔹 Две связанные таблицы: `companies` и `vacancies` (Foreign Key)
- 🔹 Защита чувствительных данных через переменные окружения

### Анализ данных (класс `DBManager`)
| Метод | Описание | SQL-особенности |
|-------|----------|----------------|
| `get_companies_and_vacancies_count()` | Список компаний с количеством вакансий | `JOIN`, `GROUP BY`, `COUNT` |
| `get_all_vacancies()` | Все вакансии с данными компании и зарплатой | `JOIN` |
| `get_avg_salary()` | Средняя зарплата по всем вакансиям | `AVG()`, `COALESCE` |
| `get_vacancies_with_higher_salary()` | Вакансии с зарплатой выше средней | Подзапрос, `WHERE`, `AVG()` |
| `get_vacancies_with_keyword(keyword)` | Поиск вакансий по ключевому слову | `ILIKE`, параметризация |

### Пользовательский интерфейс
- 🔹 Интерактивное текстовое меню
- 🔹 Человекочитаемый вывод (без сырых коллекций)
- 🔹 Форматирование зарплат: `от 100 000 ₽`, `150 000 – 200 000 ₽`
- 🔹 Поиск вакансий по ключевому слову (например, «python», «менеджер»)

## 🚀 Установка и запуск

### Предварительные требования
- ✅ Python 3.10 или выше
- ✅ [Poetry](https://python-poetry.org/docs/#installation)
- ✅ PostgreSQL 14+ и доступ к созданию баз данных
- ✅ [pgAdmin 4](https://www.pgadmin.org/) (опционально, для визуального управления БД)

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/ВАШ_НИКНЕЙМ/hh_vacancies.git
cd hh_vacancies
```

### Шаг 2: Установка зависимостей
```bash
poetry install
```

### Шаг 3: Настройка переменных окружения
```bash
# Скопируйте шаблон
cp .env.example .env

# Откройте .env в текстовом редакторе и заполните:
# - DB_PASSWORD: пароль от PostgreSQL
# - HH_USER_AGENT: User-Agent для запросов к hh.ru (рекомендуется браузерный)
```

### Шаг 4: Запуск приложения
```bash
poetry run python main.py
```
